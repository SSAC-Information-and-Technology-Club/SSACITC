# Security Policy

## Supported Versions

This is the official website of the SSAC Information and Technology Club.
Only the latest version on the `main` branch is maintained and supported.

## Reporting a Vulnerability

If you find a security problem on our website or in this repository,
please report it privately. Do not post it publicly in Issues.

Email: ssacitcwebsite@gmail.com

Please include:
- A short description of the problem
- Steps to reproduce it, if possible

We will try to reply within 7 days and fix confirmed problems as soon as we can.
